# Water–Methanol VLE Diagram

## Description
This project studies the vapor–liquid equilibrium of a water–methanol mixture at 1 atm using Python.

## Objectives
- Estimate liquid and vapor compositions at 80°C.
- Calculate liquid and vapor flow rates.
- Plot the binary T-x-y diagram.

## Conditions
- Methanol mole fraction: 0.40
- Water mole fraction: 0.60
- Total flow rate: 60 mol/h
- Pressure: 1 atm
- Temperature: 80°C

## Libraries
- NumPy
- Matplotlib
